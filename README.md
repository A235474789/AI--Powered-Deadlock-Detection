The AI-Powered Deadlock Detection System is an innovative solution designed to enhance resource management in modern operating systems. This project integrates traditional deadlock detection algorithms with artificial intelligence techniques to proactively identify, visualize, and resolve deadlocks in real time.

The system uses a Modified Resource Allocation Graph (RAG), Wait-For Graphs, and cycle detection algorithms to monitor process-resource interactions. These are enhanced with AI models such as decision trees, clustering, and predictive analysis to forecast and prevent deadlocks before they occur.

The solution also features an interactive, web-based interface built using React and TypeScript, allowing users to visualize live process states and resource allocations. This makes the system highly useful for both educational and administrative purposes.

Additionally, the system includes automated resolution strategies like resource preemption, process rollback, and priority adjustment, reducing manual intervention and significantly minimizing system downtime.

This project demonstrates how AI can be effectively applied in core operating system functions to improve efficiency, reliability, and scalability.
